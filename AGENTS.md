# AGENTS.md

**The working rules for this project are in `CLAUDE.md`. Read that file
first.** This is a signpost, not a second set of rules. It exists because
`AGENTS.md` is the name most coding agents look for.

1. `CLAUDE.md`: how to work here, and a map of where everything lives.
2. `docs/state/OPEN.md`: what Anthony has asked for and decided.

Then open only what the task needs, from the map in `CLAUDE.md`.

Do not copy `CLAUDE.md` into this file. If your tool needs another name, add
another signpost like this one.
